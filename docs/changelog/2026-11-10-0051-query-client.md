# Python query client

- `ccstats-query`: one stdlib-only Python file that queries a server from any machine (`summary`, `sessions`, `session`, `models`, `tools`, `hosts`, `dimensions`, `health`, `refresh`, raw `get`), as tables or `--json`, and as a `Client` class
- Its server comes from `--server`, `$CCSTATS_SERVER` or `~/.config/ccstats/client.toml`; `host`, `host:port` or a URL. The hub serves it at `/ccstats-query.py` preset to itself, and `ccstats script query` prints it
