# Weekly quota and the account filter on the dashboard

- Overview has a Weekly quota card: for each account with a configured quota, this window's estimated share of it (with time to the reset), the mean over the last four and over all full windows, and a column per weekly window against a dashed 100% line. Windows the account only partly covered, or still running, are lighter. It shows all time and ignores the filters.
- A new Account filter sits next to Profile; it is kept in the URL like the others.
- Filter selects are capped at 150px so the bar stays on one line on a laptop.
